# Implementation Prompt

Use this when implementing a scoped change.

1. Read `AGENTS.md` and the relevant `.agents/context/` files.
2. Identify affected modules, schema/config/docs impact, and security risks.
3. Keep the design direct and consistent with existing package boundaries.
4. Add or update tests for production behavior.
5. Update README, `config.example.toml`, or docs when user-visible behavior changes.
6. Run relevant checks and summarize the result.
