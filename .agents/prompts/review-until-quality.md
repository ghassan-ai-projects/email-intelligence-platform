# Review Until Quality Prompt

Use this before handoff on non-trivial work.

1. Re-read the changed files.
2. Check for duplicated or vague guidance.
3. Confirm commands agree across README, `AGENTS.md`, `Makefile`, CI, and `pyproject.toml`.
4. Confirm tests cover production-code behavior changes.
5. Confirm security-sensitive behavior remains guarded.
6. Run the relevant validation commands.
7. Summarize changed files, validation, residual risk, and follow-up work.
